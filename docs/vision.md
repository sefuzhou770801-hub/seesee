# seesee 愿景（2026-08-30 定案，产品方向以此为准）

## 一句话

seesee 是一个 agentic 视频播放器：它理解你正在看的内容，随时可以就此对话。

## 判断

播放器这个品类的存量竞争在「播得更好」：解码、画质、格式、皮肤。这条路上没有拉开差距的空间。差距在「看的过程」里：看视频学东西的人，真正的瓶颈不是播放，而是理解与检索。看不懂的图表、没听清的术语、想深挖的论点、看过却找不回的内容，这些都发生在播放之外，用户被迫切出去搜索、记笔记、翻历史。

agentic 播放器把这些收回到播放器之内。看时问答（ask）是这个逻辑的第一块，也是核心：任何时刻暂停提问，回答基于当前画面与前后字幕，问答钉在时间轴上可回看。它把「看视频」从单向播放变成一场对话。这是 seesee 与所有播放器拉开差距的主逻辑。

## 分层

1. **基础层（v0.1 已发布）**：干净的离线播放。粘贴链接、下载即播、双语字幕、右栏句级导航。这一层的标准是可靠与克制，它是对话层的载体，不是卖点本身。
2. **对话层（核心，v0.2 主菜）**：看时问答公开上线。含无密钥引导（归档分支 feat/qa-key-guide 续做）、密钥与开箱体验、问答留存与回看。
3. **代理层（路线）**：agent 替你处理看之外的事。跨视频检索你看过的一切、新视频下载完自动生成预审摘要、盯住你信任的频道自动收集、自动跳过赞助段。四个方向均有探索分支验证过可行性。

## 边界

- 不做在线流媒体聚合，不碰 DRM，不做推荐流。克制是产品性格的一部分。
- 对话能力不喧宾夺主：默认安静，用户主动唤起才出现。
- 隐私底线不因 agent 能力松动：无统计上报、无账号、数据全在本机；调用模型的内容（画面帧与字幕片段）仅在用户主动提问时发送。

## 对照

| | 传统播放器 | seesee |
|---|---|---|
| 定位 | 播放工具 | 看与理解的工作台 |
| 看不懂时 | 切出去搜索 | 原地问 |
| 看过的内容 | 靠记忆翻历史 | 可检索、可回看的资产 |
| 新内容 | 手动逐个筛 | agent 预审与收集 |
